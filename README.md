# 로또 분석기 (개인용 Windows 프로그램)

로또 6/45 · 연금복권 720+ 번호를 **근거와 함께** 추천하고, 구매 확정한 번호를 다음 회차 결과로 **자동 채점**하는 개인용 데스크톱 프로그램입니다.

> 추첨은 매 회 독립 시행이라 어떤 분석도 당첨 확률을 높이지 못합니다. 화면의 근거는 "과거 데이터와 이렇게 맞는다"는 설명입니다.

## 기능
| 탭 | 내용 |
|---|---|
| 로또 6/45 | 전략(균형/핫/콜드/랜덤) 선택 → 5세트 생성, 번호별 근거(핫·콜드·이월·균형)와 세트 지표(합계·홀짝·저고·AC값이 역대 몇 %에 해당하는지) |
| 연금복권 720+ | 1~5조마다 서로 다른 번호 5개씩(총 25개). 25개의 끝자리가 0~9를 모두 포함하도록 배치, 번호별 '근거 보기' |
| 구매 내역 · 채점 | 체크 후 '구매 확정'한 번호를 회차별로 저장 → 당첨번호가 들어오면 자동으로 등수 표시 |
| 당첨번호 데이터 | 자동 수집 / 수집 테스트 / 직접 입력 / 여러 회차 일괄 붙여넣기 |

- 실행 시 인터넷이 연결되어 있으면 빠진 회차 당첨번호를 자동 수집합니다. 사이트 사정으로 실패하면 `data/fetch_log.txt`에 원인이 남고, 직접 입력으로 보충할 수 있습니다.
- **Claude AI 분석**: 이 PC에 Claude Code가 설치되어 본인 계정으로 로그인되어 있으면 `claude -p`로 해설을 받아옵니다(구독 사용량에서 차감). 없으면 질문 내용을 클립보드에 복사하므로 Claude 앱에 붙여넣으면 됩니다.

## 받는 법 (exe)
1. GitHub 저장소 → **Actions** → `Build Windows EXE` → 가장 최근 성공한 실행 → 하단 **Artifacts**의 `LottoAnalyzer-windows` 다운로드
2. 압축을 풀고 `LottoAnalyzer\LottoAnalyzer.exe` 실행 (처음에 SmartScreen이 뜨면 "추가 정보 → 실행")
3. 데이터는 exe 옆 `data\lotto_data.db`에 저장됩니다. 폴더째 옮기면 기록도 같이 옮겨집니다.

## 소스로 실행
```bash
pip install -r requirements.txt
python run.py
```
